CreatiAI — حزمة النموذج الأولي

المحتويات:
- index.html: واجهة عربية لتجهيز وصف الطلب.
- manifest.json: بيانات أولية لتثبيت الواجهة كتطبيق ويب عند استضافتها.

الحالة الحالية:
هذه واجهة تجريبية فقط. لا تتصل بمولد صور/فيديو، ولا ترسل رسائل، ولا تحصّل مدفوعات، ولا تحتوي على نظام مستخدمين.

الخطوات اللازمة لتحويلها إلى خدمة حقيقية:
1) اختيار مزود توليد يتيح الاستخدام التجاري والتحقق من الأسعار والحدود.
2) إنشاء خلفية آمنة (backend) تحفظ مفتاح API بعيدًا عن المتصفح.
3) ربط الواجهة بالخلفية وإضافة حدود استخدام ومراقبة التكلفة.
4) استضافة الموقع واختباره.
5) إعداد بوابة دفع مناسبة في مصر والتحقق من إمكانية التحويل إلى المحفظة. لا تنشر رقم المحفظة علنًا قبل مراجعة إعدادات الأمان ومزود الدفع.
6) تجربة مغلقة مع عدد قليل من المستخدمين قبل أي حملة مدفوعة.

لا تضع كلمات مرور أو مفاتيح API في index.html أو ترسلها في المحادثة.
